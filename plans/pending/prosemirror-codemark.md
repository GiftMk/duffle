# Overview

Inline code blocks are a pain to get right in the browser, this is a known issue with no perfect solutions around it.
In the official prosemirror forums someone brought up a plugin they used to improve it (https://discuss.prosemirror.net/t/new-plugin-prosemirror-codemark-to-handle-inline-code-mark-creation-and-manipulation/4159).

Let's use it in our app, it's not perfect, but better than what we got now.
